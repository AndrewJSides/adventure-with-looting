# Ground textures

## What is here

`dirt-seamless.png` is real sourced art (OpenGameArt, CC0) and is used only for the
village ground around `VILLAGE_CENTER`.

`biome-NN-<slug>.png` are **procedural placeholders**, one per region id in `REGIONS`.
They were generated by `scripts/gen-placeholder-textures.py` — original output from a
seeded PRNG, no external asset, nothing to attribute.

## Replacing them

**Drop a new PNG in at the same filename and it is picked up with no code change.**
`BIOME_TEXTURE_URLS` in `App.tsx` keys these by region id, loads them lazily, builds
16 flip/rotate variants of each (so tiling never shows a repeating grid), and calls
`resetGroundChunkCache()` once loaded.

Requirements:

- **Seamless / tileable.** Chunks draw these edge-to-edge on a world-aligned lattice,
  so a non-tiling image shows visible grid seams. `gen-placeholder-textures.py` has a
  seam check at the bottom you can point at any candidate file.
- **250×250** to match `dirt-seamless.png`. Other sizes work (variants are rasterised
  at 192) but keep them square.
- **Grayscale, light-valued** for the current blend. `drawGroundTile` blits these with
  `globalCompositeOperation="multiply"`, so a grayscale tile adds surface grain without
  shifting the biome's hue. That is deliberate: dropping these in cannot change the
  existing art direction, only the flatness.

If you bring in **full-colour** art instead, change the composite op at the blit site in
`drawGroundTile` from `"multiply"` to `"source-over"` and raise the alpha — otherwise the
colour gets multiplied into the region tint and goes muddy.

## Where to source real art

License matters: `MOBILE.md` targets the App Store, so this ships commercially.

- [ambientCG](https://ambientcg.com) — CC0 seamless ground/terrain. Best fit.
- [Poly Haven](https://polyhaven.com/textures) — CC0.
- [Kenney](https://kenney.nl/assets) — CC0, no attribution required.
- [OpenGameArt](https://opengameart.org) — mixed licenses, filter to CC0. Source of the dirt.

Avoid CC-BY-SA (e.g. LPC): it requires attribution *and* share-alike on derivatives.

Verify the license per pack — it is set per asset, not per site.

## Tuning

In `App.tsx`:

| Constant | Effect |
|---|---|
| `BIOME_TEXTURE_STRIDE` | World units between blits (144). Lower = denser detail, more draw calls per chunk. |
| `BIOME_TEXTURE_SPAN` | Drawn size, `STRIDE * 1.22`. The overlap hides tile boundaries. |
| `BIOME_TEXTURE_ALPHA_BASE` / `_RANGE` | Blend strength, jittered per tile. Raise for heavier texture. |

## Performance

Each blit is one `drawImage` inside the chunk `tiles` phase, which is already budgeted
incrementally, and results are cached per chunk. But chunk building is capped by
`GROUND_CHUNK_DRIVING_DRAW_BUDGET` (72 draw calls) while driving, so denser textures mean
fewer chunks completing per frame on the move.

Toggle it live with the **Ground tex** switch in the profiler's effect row (it is also
turned off by **Minimal Mode**), and compare the WORST FRAME readout with it on and off.
